# Notion API Module

This module provides API integration and Fenestra UI extension specifications for Notion.

## Fenestra UI Extensions

This module includes comprehensive Fenestra specifications for Notion UI extensibility.

### Available Extension Types
See `fenestra/platform.fenestra.yaml` for complete specification.

### Examples
Check `fenestra/examples/` directory for implementation examples.

## Installation

```bash
npm install @api-modules/notion
```

```javascript
const notionAPI = require('@api-modules/notion');
```
