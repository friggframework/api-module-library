# pipedrive

This is the API Module for pipedrive that allows the [Frigg](https://friggframework.org) code to talk to the pipedrive
API.

Read more on the [Frigg documentation site](https://docs.friggframework.org/api-modules/list/pipedrive
## Fenestra UI Extensions

This module includes Fenestra specifications for Pipedrive UI extensibility.

### Available Extension Types
See `fenestra/platform.fenestra.yaml` for complete specification.

### Examples
Check `fenestra/examples/` directory for implementation examples.
