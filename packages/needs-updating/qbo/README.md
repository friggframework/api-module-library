# qbo

This is the API Module for qbo that allows the [Frigg](https://friggframework.org) code to talk to the qbo API.

Accounting API requests pin `minorversion` to **75** via `DEFAULT_MINOR_VERSION`
(see `api.js`). Value verified from Intuit’s
[minor versions](https://developer.intuit.com/app/developer/qbo/docs/learn/explore-the-quickbooks-online-api/minor-versions)
changelog (highest listed version; 1–74 discontinued 2025-08-01).

Read more on the [Frigg documentation site](https://docs.friggframework.org/api-modules/list/qbo).
